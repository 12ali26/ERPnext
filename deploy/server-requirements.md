# Server Requirements

## Pilot

- Ubuntu 24.04 LTS VPS
- 4 vCPU
- 8 GB RAM
- 80 GB SSD
- Public IPv4 address
- Domain pointed to the server
- SSH access with sudo

## Production

- Ubuntu 24.04 LTS VPS
- 8 vCPU
- 16 GB RAM
- 160 GB SSD
- Off-server backups
- Monitoring
- SSL certificate

## Access Needed To Deploy

Provide:

- Server IP
- SSH username
- SSH key or password
- Domain/subdomain
- Preferred admin email
- Final company name
